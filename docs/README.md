# Documentação do App da Loja

A documentação operacional completa deste projeto é mantida em ambiente privado.

Este repositório público contém somente a interface de desenvolvimento e arquivos que podem ser expostos publicamente.

## Arquitetura

- GitHub Pages: interface;
- Google Apps Script: backend e regras;
- Google Sheets: banco operacional;
- Google Drive: fotos;
- PWA: interface instalável.

## Segurança

Não devem ser publicados neste repositório:

- dados de clientes;
- telefones;
- custos, margens ou pagamentos;
- chaves, tokens, PINs ou senhas;
- IDs e links privados;
- exportações reais do banco;
- backups;
- regras administrativas sensíveis.

## Método

O desenvolvimento segue:

1. uma função por vez;
2. teste no DEV;
3. validação no celular;
4. checkpoint;
5. commit do bloco funcional;
6. Produção somente após validação do núcleo.
